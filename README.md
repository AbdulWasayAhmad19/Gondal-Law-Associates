# Gondal Law Associates — Next.js Website

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build for production
```bash
npm run build
npm start
```

## Structure
- `app/` — layout, page, global styles
- `components/` — Navbar, Hero (auto-changing slideshow), Practice, Advocates, Stats, FAQ, Contact, Footer, Consultation Popup, WhatsApp float
- `public/images/` — team & portrait photos

## Editing content
- Phone numbers / WhatsApp: search for `923334391854`
- Practice areas: `components/Practice.jsx`
- FAQs (English + Urdu): `components/FAQ.jsx`
